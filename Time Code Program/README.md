# TimeCode Assignment

## Description

This program represents a duration of time using hours, minutes, and seconds.

The TimeCode class stores the total amount of time as seconds and uses that value to calculate the hours, minutes, and seconds.

## Files

- `TimeCode.h` — class declaration
- `TimeCode.cpp` — TimeCode class implementation
- `TimeCodeTests.cpp` — tests for the TimeCode class
- `Makefile` — compiles the program

## How to Compile

Run:

```bash
make
